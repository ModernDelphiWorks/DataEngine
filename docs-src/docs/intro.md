# Portal de Documentação

Seja bem-vindo ao portal de documentação técnica do ecossistema. Aqui você encontrará guias, referências de API e arquitetura para nossos frameworks.

## DataEngine

Framework de abstração de acesso a dados (DBA) para Delphi. Proporciona desacoplamento total de engines (FireDAC, UniDAC, DBExpress, Zeos, etc.).

> [!NOTE]
> O framework **DataEngine** é a evolução oficial do antigo framework **DBEBr**.
